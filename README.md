# Toogle

Real-time service marketplace platform with instant availability toggling.

## Features

- **Real-Time Availability Toggle** - Service providers can toggle availability on/off instantly
- **Geolocation Search** - Find the closest available service providers near you
- **Hours & Pricing** - View service hours and upfront pricing
- **Review-Based Recommendations** - Smart recommendations based on previous reviews
- **QR Code Blockchain Tracking** - Every service contract tracked via QR codes on the blockchain
- **Samiteon Payment Integration** - Secure payments through Samiteon charge card services
- **Quote Engine** - Request and receive instant quotes
- **Instant Messaging** - Real-time chat between customers and providers
- **Provider Pages** - Dedicated pages with blogs, podcasts, videos, audio, and service listings

## Tech Stack

- React + Vite
- Tailwind CSS
- Node.js

## Getting Started

```bash
npm install
npm run dev
```
